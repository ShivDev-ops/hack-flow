# UI/UX Pro Max

## Operational Workflow

1.  **Analyze Requirements**: Extract product type, style keywords (e.g., "minimalist", "brutalist"), and tech stack.
2.  **Generate Design System**: Recommend a pattern, color mood, and typography based on the product context.
3.  **Apply Standards**: Implement components following professional UI rules and accessibility guidelines.

## Professional UI Rules

- **No Emoji Icons**: Always use SVGs (Lucide, Phosphor, or Heroicons).
- **Interactive Feedback**: Every clickable element must have a `cursor-pointer` and a hover state.
- **Motion**: Use smooth transitions (150ms–300ms) for state changes.
- **Accessibility**: Maintain a minimum 4.5:1 contrast ratio; ensure visible focus rings for keyboard navigation.
- **Spacing**: Adhere to a strict 4px or 8px grid system.
